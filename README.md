# Even and Odd File Sorter

A Python script that reads a list of numbers from a text file,
separates them into even and odd numbers, writes each group
to its own output file, and displays the results.

## What It Does
- Reads numbers from numbers.txt line by line
- Separates them into even and odd lists
- Writes even numbers to even.txt
- Writes odd numbers to odd.txt
- Prints both lists to the console
- Skips empty lines automatically

## Files
- numbers.txt — input file containing one number per line
- even.txt — output file for even numbers
- odd.txt — output file for odd numbers

## Sample Output
Even numbers: [2, 4, 6]
Odd numbers:  [1, 3, 5]

## Requirements
- Python 3.x
- A numbers.txt file in the same folder as the script
